Selected Work

ContainmentBench

In progress

Building an evaluation environment for studying whether deterministic isolation and trajectory-aware security controls can contain autonomous coding agents exposed to untrusted instructions across multi-step tasks.

Hidden Reliability Failures in Malware Detection

Evaluated the released EMBER2024 detector across 1.08M Windows PE files. Despite 98.0% aggregate accuracy and 0.0031 ECE, family-conditioned analysis uncovered malware families with greater than 0.60 ECE and greater than 80% false-negative rates.

Inferring Vulnerability Attributes from CVE Descriptions

Built a temporal benchmark for predicting CVSS, CWE, severity, and CVSS-vector components from vulnerability descriptions. On 36K+ held-out 2024 CVEs, simple TF-IDF baselines outperformed zero-shot 70B+ language models on severity and CWE prediction, while exposing large failures on rare classes and attributes requiring implicit inference.

Compliance Reality Checker

Built Linux and Microsoft 365 security checks that distinguish controls that appear configured from controls that are actually enforced, incorporating global policy, account-level exceptions, and runtime state.

A First Look at Governments' Enterprise Security Guidance

Contributed to a Stanford Empirical Security Research Group study of government enterprise-security guidance spanning 41 countries. Among ten deeply analyzed frameworks, only 2 of 166 observed controls were universally recommended, with substantial disagreement even among close security allies.

About

I'm a computer science student at Stanford working across empirical security and AI security. A recurring question in my work is whether the signals we rely on — model confidence, security guidance, compliance checks, or system safeguards — actually correspond to security when their assumptions are stressed.

I especially like projects where the aggregate result initially says everything is working and the interesting part begins when you ask what that result might be hiding.
